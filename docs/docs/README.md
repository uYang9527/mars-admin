# Mars Admin

> 一个现代化的企业级后台管理系统，基于Spring Boot 3和Vue 3

## 项目介绍

Mars Admin是一个开箱即用的企业级后台管理系统，采用前后端分离架构，提供完整的用户权限管理、部门管理、角色管理、菜单管理等功能，并集成了高效的SQL监控系统。项目使用最新的技术栈，提供现代化的开发体验和用户界面。

## 技术栈

### 后端技术

- **基础框架**：Spring Boot 3.0.5
- **JDK版本**：Java 17+
- **ORM框架**：MyBatis-Flex 1.10.9
- **权限认证**：Sa-Token 1.38.0
- **数据库**：MySQL 8.x
- **缓存**：Redis
- **其他**：Lombok, Hutool, Knife4j

### 前端技术

- **核心框架**：Vue 3.5.13 + TypeScript
- **构建工具**：Vite 6.1.0
- **UI组件**：Ant Design Vue 4.2.6
- **状态管理**：Pinia 3.0.0
- **路由**：Vue Router 4.3.0
- **HTTP客户端**：Axios
- **图表**：ECharts 5.5.0

## 核心功能

- **用户管理**：用户是系统操作者，该功能主要完成系统用户配置
- **角色管理**：角色菜单权限分配、设置角色按机构进行数据范围权限划分
- **菜单管理**：配置系统菜单、按钮、API等权限
- **部门管理**：配置系统组织机构（公司、部门、小组）
- **岗位管理**：配置系统用户所属担任职务
- **字典管理**：对系统中经常使用的一些较为固定的数据进行维护
- **参数管理**：对系统动态配置常用参数
- **通知公告**：系统通知公告信息发布维护
- **操作日志**：系统正常操作日志记录和查询
- **登录日志**：系统登录日志记录和查询
- **文件上传**：服务器本地上传和阿里云OSS上传
- **SQL监控**：对系统的SQL执行情况进行监控，支持慢查询分析

## 系统特点

- **前后端分离**：采用前后端分离架构，提高开发效率
- **权限管理**：基于RBAC的权限管理，细粒度控制
- **数据监控**：内置强大的SQL监控系统，帮助优化性能
- **多主题**：支持多种主题切换，满足不同审美需求
- **国际化**：支持中英文切换，轻松应对国际化需求
- **组件封装**：高度封装的组件库，提高开发效率
- **响应式设计**：支持PC和移动端，提供良好的用户体验
