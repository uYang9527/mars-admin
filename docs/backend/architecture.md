# 后端技术架构

Mars Admin后端采用现代化的Java技术栈，基于Spring Boot框架构建，提供高性能、可扩展的API服务。

## 技术选型

### 核心框架

- **Spring Boot 3.0.5**: 提供自动配置、依赖管理和嵌入式服务器
- **JDK 17+**: 利用最新Java特性，如记录类型、文本块、密封类等
- **MyBatis-Flex 1.10.9**: 增强版MyBatis，提供更灵活的ORM功能
- **Sa-Token 1.38.0**: 轻量级Java权限认证框架

### 数据存储

- **MySQL 8.x**: 主要关系型数据库
- **Redis**: 缓存和会话存储

### 工具库

- **Lombok**: 减少模板代码
- **Hutool**: 通用工具集
- **Knife4j**: API文档生成工具
- **Jackson**: JSON处理
- **Druid**: 数据库连接池

## 核心组件

### 认证授权

Mars Admin使用Sa-Token实现认证授权功能：

- **认证流程**：用户登录 -> 验证凭证 -> 生成令牌 -> 存储会话
- **权限控制**：基于RBAC模型，支持角色和权限两级控制
- **会话管理**：使用Redis存储会话，支持多端登录控制
- **记住我**：支持长时间保持登录状态
- **路由守卫**：对API接口进行权限拦截

### 数据访问

系统使用MyBatis-Flex作为ORM框架：

- **灵活查询**：支持Lambda表达式构建查询条件
- **分页查询**：内置分页功能
- **多数据源**：支持配置多个数据源
- **自动填充**：支持字段自动填充
- **乐观锁**：内置乐观锁支持

### 缓存设计

系统采用多级缓存策略：

- **本地缓存**：使用Caffeine实现JVM内存缓存
- **分布式缓存**：使用Redis实现分布式缓存
- **缓存策略**：按业务需求设置TTL和更新策略
- **缓存穿透保护**：使用空值缓存和布隆过滤器

### 异常处理

全局统一的异常处理机制：

- **业务异常**：自定义业务异常类型
- **系统异常**：包装系统异常，提供友好提示
- **参数校验异常**：统一处理参数校验失败
- **权限异常**：处理认证和授权失败

## 关键流程

### 请求处理流程

```
HTTP请求
   ↓
过滤器链 (跨域、安全等)
   ↓
拦截器 (认证、日志等)
   ↓
控制器 (参数校验、业务处理)
   ↓
服务层 (业务逻辑)
   ↓
数据访问层 (CRUD操作)
   ↓
响应生成 (统一格式)
   ↓
HTTP响应
```

### 登录认证流程

```
用户提交凭证
   ↓
验证用户名密码
   ↓
生成Token
   ↓
存储会话信息
   ↓
返回Token给客户端
   ↓
后续请求携带Token
   ↓
验证Token有效性
   ↓
授权访问资源
```
