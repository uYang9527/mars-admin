# 更新日志

本文档记录了Mars Admin项目的所有重要变更。

## [1.0.0] - 2024-06-01

### 新增功能

- 完整的RBAC权限管理系统
  - 用户管理
  - 角色管理
  - 菜单管理
  - 部门管理
  - 岗位管理
- 基于Sa-Token的认证授权系统
  - 登录认证
  - 权限控制
  - 会话管理
- 系统管理功能
  - 字典管理
  - 系统配置
  - 操作日志
  - 登录日志
- 文件上传功能
  - 本地存储
  - 阿里云OSS存储
- SQL监控系统
  - 实时SQL日志
  - 慢查询分析
  - 性能统计
- 前端功能
  - 响应式布局
  - 多主题支持
  - 国际化支持
  - 表格列设置
  - 搜索区域折叠

### 技术栈

- 后端：Spring Boot 3.0.5 + Java 17
- ORM：MyBatis-Flex 1.10.9
- 认证：Sa-Token 1.38.0
- 数据库：MySQL 8.x
- 缓存：Redis
- 前端：Vue 3.5.13 + TypeScript
- 构建工具：Vite 6.1.0
- UI组件：Ant Design Vue 4.2.6
- 状态管理：Pinia 3.0.0

## 版本号说明

Mars Admin使用[语义化版本控制](https://semver.org/)：

- 主版本号（x.0.0）：不兼容的API变更
- 次版本号（0.x.0）：向后兼容的功能性新增
- 修订号（0.0.x）：向后兼容的问题修正
